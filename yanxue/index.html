选择一节课，
自动整理成学习笔记。

把教学网录播、课程课件、音频转录和笔记整理接在同一个工作台里。下载到你的电脑，登录自己的账号，在本机运行完整处理流程。

下载 Windows 版 ZIP查看源码与说明

需要 Python 3.11+、FFmpeg/FFprobe 和已有 PKU-Recorder。首次启动联网安装依赖。

01 · 一次安装

解压，双击启动

首次双击“一键安装并启动.cmd”，选择已有下载器目录。之后打开“打开可视化界面.cmd”即可。

02 · 同一页面

一键完成整条流程

选择课程与录播，自动下载、汇集课件、转录、生成笔记和质检。在页面内修改并定稿。

03 · 多学科

课程不同，笔记也不同

经济学、理工、人文社科、法学、语言和通用模板，保留教师观点、例子与材料出处。

开始使用

  1. 下载 ZIP 并完整解压，确认电脑已安装 Python 3.11+ 和 FFmpeg/FFprobe。
  2. 首次双击“一键安装并启动.cmd”，安装依赖并选择已有 PKU-Recorder 目录。
  3. 在 Windows 用户环境变量中设置 OPENAI_API_KEY，重新启动工作台。
  4. 在工作台内登录教学网，选择录播，点击“一键生成学习资料”。

本页是下载入口。课程处理在本机工作台运行；正式 AI 生成会把所需音频与课程文本发送给你配置的 AI 服务，并可能产生 API 费用。没有有效 Key 时可使用离线证据提取。源码版尚未包含免安装 EXE。
