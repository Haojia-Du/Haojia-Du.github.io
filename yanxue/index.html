开始使用

  1. 优先下载 Windows 安装版，安装后从开始菜单启动；无需另外安装 Python。安装包未签名，Windows 可能提示安全风险。
  2. 以后双击桌面上的“燕学”即可，程序自动选择地址并打开学习页。
  3. 首次在右上角“设置”连接自己的 AI 服务；不使用教学网时无需配置下载器。
  4. 选择录播或课件，点击“开始整理”，完成后在“我的笔记”中直接阅读。

本页是下载入口。课程处理在本机工作台运行；正式 AI 生成会把所需音频与课程文本发送给你配置的 AI 服务，并可能产生 API 费用。没有有效 Key 时可使用离线证据提取。PPTX/DOCX 显示提取内容，PDF 可原版预览；Windows 安装／便携包为可选下载；源码版继续保留。
