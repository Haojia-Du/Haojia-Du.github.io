01 · 启动方式任选

源码启动或 Windows 安装

保留轻量源码包，也可选择无需外部 Python 的 Windows 安装版。更新仅手动检查，不自动下载安装。

02 · 整门课可选

批量处理，随时续跑

勾选部分录播或全选，逐节生成笔记，可选复习包。当前节完成后可暂停，重开后保留已完成进度。

03 · 各门课独立保存

模板、术语和课程工作区

每门课保存自己的模板、术语表与补充要求。单节处理、同页核对和问答卡片继续可用。

开始使用

  1. 优先下载 Windows 安装版，安装后从开始菜单启动；无需另外安装 Python。安装包未签名，Windows 可能提示安全风险。
  2. 按工作台顶部的首次使用提示，检查并按需安装音频与浏览器组件。
  3. 在页面“连接设置”中填写下载器目录、AI 服务地址、密钥与模型，保存并测试。
  4. 先选择本地录播试跑前3分钟，核对效果后处理整节或整门课；失败时按类别提示续跑。

本页是下载入口。课程处理在本机工作台运行；正式 AI 生成会把所需音频与课程文本发送给你配置的 AI 服务，并可能产生 API 费用。没有有效 Key 时可使用离线证据提取。PPTX/DOCX 显示提取内容，PDF 可原版预览；Windows 安装／便携包为可选下载；源码版继续保留。
