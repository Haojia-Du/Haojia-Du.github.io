需要 Python 3.11+、FFmpeg/FFprobe 和已有 PKU-Recorder。首次启动联网安装依赖。

01 · 继续处理

中断后，从断点继续

已下载材料、已完成转录和笔记段落会保留。网络或密钥问题解决后，点击重试即可继续。

02 · 同页学习

录播、课件和笔记同屏

页面内设置连接，播放录播、阅读课件与公式，点击笔记出处跳到原材料的位置。

03 · 主动复习

自测题、卡片、提纲

依据保存的课程笔记生成复习包。先回答再看答案，卡片翻面并记录掌握情况。

开始使用

  1. 下载 ZIP 并完整解压，确认电脑已安装 Python 3.11+ 和 FFmpeg/FFprobe。
  2. 首次双击“一键安装并启动.cmd”，之后日常双击“打开可视化界面.cmd”。
  3. 在页面“连接设置”中填写下载器目录、AI 服务地址、密钥与模型，保存并测试。
  4. 选择课程录播一键处理；在“在此阅读”学习台中核对、修改笔记，再生成复习包。

本页是下载入口。课程处理在本机工作台运行；正式 AI 生成会把所需音频与课程文本发送给你配置的 AI 服务，并可能产生 API 费用。没有有效 Key 时可使用离线证据提取。PPTX/DOCX 显示提取内容，PDF 可原版预览；源码版尚未包含免安装 EXE。
