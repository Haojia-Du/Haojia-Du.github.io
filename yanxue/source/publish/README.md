# 燕学工作台 v0.6.0

面向北京大学学生的本机学习工具：从教学网课程录播、课件和转录稿生成可追溯的 Markdown 笔记。

## 日常只做三步

双击桌面上的“燕学”，程序会自动打开学习页；不用记网址、端口或程序路径。安装时默认勾选桌面图标，也可取消。

首页选择本地录播／课件，或切换“教学网课程”，然后点击“开始整理”。本地材料会自动导入并生成笔记，不再分成“先导入、再到书架生成”两步。笔记名称按文件名自动填写，可以修改。完成后在“我的笔记”卡片中点击“阅读笔记”。

首次使用仍需在右上角“设置”连接自己的 AI 服务，费用由所选服务决定；勾选加密保存密钥后下次无需重填。暂时不连接 AI，也可点击“先整理原文”，不会调用 AI 或自动转录音视频。教学网仅在需要时连接，下载器目录可用“选择文件夹”填写。

试跑、用量限制、自动监听、日志、诊断、导入工具和课程模板都保留在设置中；首页默认不展示这些高级控制。批量处理保留在教学网课程入口。失败时首页给出下一步建议，技术详情收进设置。没有删除已有材料、笔记或功能。

## 下载与启动（详细说明）

两种方式任选，批量处理和组件安装也均为可选功能：

- Windows 安装版：从 GitHub Releases 下载 `Yanxue-Setup.exe`，按提示安装后从开始菜单启动。无需另外安装 Python，桌面快捷方式可自行勾选。
- Windows 便携版：下载 `yanxue-portable.zip`，解压并双击 `Yanxue.exe`。同样无需外部 Python。
- 源码版：继续使用下述脚本方式启动，保留开发和定制能力。

Windows 安装版和便携版的数据默认保存在 `%LOCALAPPDATA%\Yanxue`，与程序文件分开。安装新版本会创建新的程序目录并保留旧版本，不自动覆盖运行中的程序。FFmpeg、FFprobe、Chromium 不包含在安装包中，可在页面“连接设置 → 组件与版本”检查并按需安装。安装浏览器组件会联网下载 Chromium；FFmpeg 按需安装通过 Windows 的 winget 完成，若系统要求交互处理则显示失败提示，不自动接受额外条款。

本发布包未使用代码签名证书。安装程序会写入当前用户的程序目录和开始菜单快捷方式，无需为本工具授予管理员权限。

在下载页面获取 `yanxue-windows.zip`，解压到普通文件夹，首次双击 `一键安装并启动.cmd`。安装完成后，日常双击 `打开可视化界面.cmd`。

需要 Windows、Python 3.11 或更新版本，以及已安装并加入 PATH 的 FFmpeg/FFprobe。首次安装需要联网下载 Python 依赖和 Chromium。

首次启动后，在页面“连接设置”中填写已有 PKU-Recorder 的项目目录。该目录应包含 `pku_recorder_app/app.py`；也可填写直接包含 `app.py` 的目录。下载器需使用与本工具适配的 Web API。PKU-Recorder 是独立安装的工具，不包含在本发布包内。

不配置下载器也可导入本地视频、音频、PDF、PPTX、DOCX、TXT 和 Markdown。

在页面“连接设置”中填写 AI 服务地址、API Key、笔记模型、审计模型和转录模型，然后点击“保存并测试连接”。密钥默认仅本次运行可用；选择“用 Windows 加密保存新密钥”可在下次启动时自动读取。原有 `OPENAI_API_KEY` 与 `OPENAI_BASE_URL` 环境变量仍兼容，无需改动。连接测试验证服务与密钥，模型支持情况由实际请求验证。没有有效密钥时可用“只提取证据”。转录、笔记、审计和复习生成会调用配置的服务并按其规则计费。

## v0.4 首次使用与保护

页面顶部新增首次使用检查和同页配置导航。可填写已下载音视频路径，明确确认发送后，试跑前3分钟并生成独立课程单元；重试复用样本，不改原录播。试跑不包含完整课件，也不能证明整节材料均可正确处理。

本页的手动 AI 生成与整个自动监听会话共用所填写的请求上限规则（默认100次），失败重试计数；达到上限会在下一次网络请求前停止。监听跨轮次累计用量，任何失败都会停止监听，不自动重新分配额度。手动恢复或重新开启会重新分配额度，发起前提示确认。点击停止监听后不再发起新的 AI 请求，已发出的请求无法撤回。上限不是金额上限：单次请求收费不同，实际金额以供应商账单为准。费用计算器只按使用者填写的统一币种、时长和单价估算，不获取供应商价格。

v0.6.0 可用“选择试跑文件”打开 Windows 文件选择器，无需手填路径。仅选择文件不会发送材料；更换文件后需要重新确认。文件选择器支持中文路径。

批次可以取消（当前节先完成）或在停止后跳过失败节次；取消保留已有材料。首节共用课件尚未获取时不能跳过，避免后续缺少课件。

v0.4 功能通过请求拦截、重试计数、批次取消／跳过和真实 FFmpeg 样本裁剪测试；未使用个人账号或付费 AI 验收真实课程。

## v0.5 稳定性与全文审计

语义质检改为按全部材料批次逐段核对，不再静默截取前50000字符。超长笔记按20000字符分片，完整覆盖各片文本；每片审计结果单独缓存，中断后只请求未完成片段。`generated/qa_coverage.json` 记录批次与字符覆盖信息。当前是各批次局部核对，不保证跨批次全局一致，也不等于事实正确；长笔记分片时遗漏主题仍需人工核对。审计调用可能增加，受同一请求次数上限约束。

损坏的连接配置、课程模板、任务／批次记录和用量记录不会再直接导致整个界面打不开。原文件不在启动时删除或覆盖；使用者明确重新保存配置或启动替代任务时，先在原目录保留 `.corrupt-<随机编号>.bak` 备份。备份可能包含私密配置，请只保存在本机。连接／模板配置异常时暂停使用 AI 密钥，避免回退到其他服务地址；请重新保存后再使用。

页面顶部可下载脱敏诊断 JSON：只包含版本、组件可用性、剩余磁盘空间、检验计数、请求用量和故障类别，不含密钥、账号、课程名称、材料、原始日志与文件路径。导出不自动上传。任务失败提示故障类别和恢复建议；磁盘写入失败不再把运行状态永久卡在忙碌。旧版仍占用端口时，新版提示先结束旧任务，不自动中断或替换运行中的程序。

本轮增加长材料审计、审计断点、损坏记录恢复、诊断脱敏及本机访问保护测试。仍未使用个人账号或付费模型验收真实课程，浏览器交互检查不等于实际浏览器视觉验收。

v0.6.0 增加本地失败检验：空文件、丢失的引用材料、未提取出文本的课件、空转录、转录时间缺口或总时长不符、模型返回缺字段或空正文、空复习包都不会标记成功。无效分段缓存会在下次处理时重新请求，正常分段继续复用；不自动额外重试 AI 语义失败。下载进度15分钟不变会提示检查，不新建重复下载。

每节课的 `generated/validation.json` 保存检验阶段、结果和原因，书架显示“处理未通过／待人工核对”，可点击“重新检验并续跑”。失败初稿不能直接一键定稿，仍可人工编辑核对后保存定稿。完成缓存校验笔记、质检报告与证据文件摘要，文件被修改或损坏时重新检验。结构检验通过不等于内容完全正确；静音可能被判为空转录，需要试听确认；偏短笔记、缺少来源、语义审计问题和超长材料的审计截断会提示人工核对。

在工作台启动教学网连接，使用自己的账号登录，选择课程、录播和笔记类型，点击“一键生成学习资料”。后台依次下载录播、汇集课件、转录音频、整理笔记、输出质检报告。

笔记支持经济学、理工科、人文社科、法学、语言和通用课程。点击“在此阅读”打开学习台：左侧播放音视频、预览 PDF 或阅读课件提取内容，右侧显示排版后的笔记与公式，也可切换到 Markdown 编辑。新生成笔记中的 `〔来源：文件名｜页码或时间范围〕` 可点击跳转到对应材料位置。PPTX/DOCX 当前显示提取的页面或段落文本，不复原原始版式。

## 失败重试与断点

任务失败后在页面顶部显示原因与“从断点重试”。任务记录保存在本机，关闭或中断后重开仍可手动续跑。已完成的下载任务、音频转录片段与笔记段落会复用；更改材料、模型或提示词会使对应内容缓存失效。失败的材料不会被错误标成“已同步”。同步模式只在本轮材料处理成功后确认该组完成。

## 整门课处理（可选）

登录并选择课程后，展开“整门课批量处理”，勾选部分录播或全选，点击开始。默认逐节生成笔记和质检报告；可另行勾选每节完成后生成复习包，这会增加 AI 调用。课程附件在批次第一节获取后复用，不逐节重复下载。

任务可在当前节处理完成后暂停，暂停和失败均支持继续；电脑或程序重开后，已完成节次保留，不自动开始新的 AI 调用。失败时批次停止，解决错误后继续处理未完成节次。批次记录保存在该课程的 `.batch-progress.json`。

“笔记书架”右上角可切换已有本机课程。每门课可分别保存笔记模板、术语表和补充提示要求；再次打开会恢复上次课程。术语用于语音转录提示，补充要求用于笔记生成。

## 组件与更新（可选）

启动时只检查本机依赖状态，不自动安装组件，也不联网检查新版本。展开“连接设置 → 组件与版本”，可按需安装浏览器、尝试安装 FFmpeg，或点击“手动检查更新”。检查更新只读取公开版本号，不下载、不安装、不替换当前程序；发现更新后由使用者选择打开下载页。

## 自测与复习

保存笔记后，点击学习台中的“生成复习包”。程序优先采用定稿，没有定稿则采用初稿，生成自测题、问答卡和考前提纲。自测题默认隐藏参考答案；卡片支持翻面和记录“还需复习／已掌握”，进度保存在本机。笔记改动后会显示复习包过期提示，可重新生成。支持导出完整 Markdown 复习包。考前提纲只整理笔记，不预测考试范围。

离线证据包需先生成正式笔记，或由使用者整理并保存为定稿后，才能生成复习包。

## 数据与配置

课程区保存在 `workspaces/`。连接配置保存在 `local-settings.json`；加密密钥仅当前 Windows 账号可解密。任务恢复信息保存在 `local-task.json`。这些文件均不进入发布仓库。教学网密码不写入笔记、配置或日志，只转发给本机下载后台。教学网会话由原有下载器管理。工作台默认仅监听 `127.0.0.1:8765`。

课程文件在本机保存；选择正式 AI 生成后，音频和提取的课程内容会发送给你配置的 AI 服务。请按课程材料的使用要求处理和分享笔记。

自定义提示词位于课程区的 `prompt.md`，模型与术语配置位于 `course.toml`。页面中的“课程工作区”显示当前数据位置。

## 当前边界

源码版需要 Python；可选 Windows 安装／便携版自带运行环境。教学网登录和正式 AI 生成仍需使用者提供有效账号及 API Key。课件与录播尚未实现精确逐页视觉对齐，当前按页码文本与分段转录共同生成笔记。浏览器需支持 MathML 以显示数学公式。

v0.6.0 通过真实 FFmpeg、工作台 HTTP 接口和可控 AI 测试服务完成“导入、转录、失败重试、笔记、审计、复习包”验收，并验证批次暂停、失败恢复、课程隔离与 Windows 打包程序启动。下载器兼容性通过独立工作进程测试；不等同于已验证每个使用者的教学网账号、AI 供应商或模型。浏览器自动预览仍不可用，布局需实际浏览器试用反馈。

## 第三方组件

本包包含 markdown-it 14.1.0 和 Temml 0.14.0，用于本机笔记排版和 MathML 公式显示。对应许可证位于 `course_notes/web/vendor/`，无需运行时从 CDN 加载。

Windows 包的其他组件许可证收录于 `third-party-licenses/`；PDF 文本提取使用 pypdf。源码环境仍可选装 PyMuPDF 以保留逐页图片提取。

## 开发

从旧版更新时，请将新版解压到新文件夹，保留旧版备份；把原来的 `workspaces/`、`local-settings.json`（若存在）和 `local-task.json`（若存在）复制到新版同名位置，再运行“一键安装并启动.cmd”。加密密钥仅同一 Windows 账号可读。正在处理的任务请先结束或中断后再迁移。

从源码版迁移到 Windows 版，可将上述数据复制到 `%LOCALAPPDATA%\Yanxue`。原工作区中的外部材料引用依赖原文件位置，请保留原下载目录。

```powershell
python -m pip install ".[documents,recorder]"
python -m playwright install chromium
python -m unittest discover -s tests -v
python -m course_notes.launcher
```

Windows 构建：在隔离环境中安装 `pyinstaller` 和 `.[documents,recorder]`，执行 `python scripts/build_windows.py`，再运行 `python scripts/smoke_windows.py dist/windows/Yanxue/Yanxue.exe` 验证。构建产物位于 `dist/windows/`。GitHub Actions 的可选 Windows 发布流程使用同一构建脚本。
